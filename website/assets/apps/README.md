# Third-party app artwork

These original SVGs are unchanged upstream assets. They are not covered by
Miami Cruise's MIT licence. Each adjacent JSON record identifies the creator,
commit-pinned source, licence, evidence and review date. Applicable full licence
notices are included here. Neovim's logo is by Jason Long, CC BY 3.0:
https://creativecommons.org/licenses/by/3.0/

The build copies this directory and publishes the records as `credits.html`.
Names and trademarks belong to their respective owners. Their inclusion identifies
supported applications and does not imply endorsement.

When no suitable original artwork with documented reuse terms is available, use
the existing GUIDE text fallback. Do not substitute an unofficial logo or infer
artwork permissions solely from a project's software licence.
